# AlgebraWalk
I'm working to hack/mod this game to gain experience and learn from it.

* Publish an unbeatable level (bypass verification which should be easy)
* Give myself everything
* Find a way to noclip
* Reverse engineer the main levels and implement them into the level editor
* Add my own custom level to the main level list

 I'm sure most if not all of these have already been accomplished, and I don't care.
 My goal is to learn how to do all of it myself without any assistance/past research that may be out there already from other reverse engineers.
